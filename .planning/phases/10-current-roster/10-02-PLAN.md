**`/roster-import` command (per D-01 through D-08):**
- Decorators: `@require_sport_channel()` and `@is_recruiting_editor()` (same pattern as transfers.py -- define both locally)
- Immediately `await interaction.response.defer(ephemeral=True)` (per D-07)
- Resolve sport from channel via `get_sport_from_channel(interaction.channel_id, interaction.client.settings)`
- Call `fetch_football_roster(bot.settings)` or `fetch_basketball_roster(bot.settings)` based on sport
- **Empty roster safety (per Pitfall 6 from RESEARCH.md):** If API returns 0 players, do NOT clear existing roster. Instead respond: "API returned no players for Kansas {sport}. Existing roster preserved. This may be an offseason issue."
- **Replace mode (per D-02):** Set `bot.roster_store._data[sport] = []` to clear, then build new entries
- For each player dict from the fetch function, create a `PlayerEntry`:
  ```python
  entry = PlayerEntry(
      name=p["name"],
      position=p["position"],
      school="",  # per D-11: always Kansas, store empty
      stars=0,    # per D-10: unrated for roster
      type="roster",
      jersey_number=p["jersey_number"],
      class_year=p["class_year"],
  )
  ```
- **Stats fetch per player (per D-03):** For each entry, fetch stats using existing functions. Use `try/except` with fire-and-forget pattern (failure does not block):
  ```python
  try:
      if sport == "football":
          stats = await fetch_football_stats(bot.settings, p["name"], "Kansas")
      else:
          stats = await fetch_basketball_stats(bot.settings, p["name"], "Kansas")
      if stats:
          entry.stats = stats
          stats_success += 1
  except Exception:
      logger.warning(f"Failed to fetch stats for {p['name']}", exc_info=True)
  ```
- Append entry to `bot.roster_store._data[sport]`
- **Progress update (per RESEARCH.md discretion):** At the 50% mark (when `i == len(players) // 2` and `len(players) > 20`), call `await interaction.edit_original_response(content=f"Importing... {i}/{len(players)} players processed")`
- After all players: call `bot.roster_store.save()` ONCE (not per player -- per Pitfall 3)
- Final response (per D-07): `await interaction.edit_original_response(content=f"Imported {len(players)} {sport} players. Stats loaded for {stats_success}, failed for {len(players) - stats_success}.")`

**`/roster-list` command (per D-13 through D-15):**
- Decorators: `@require_sport_channel()` only (no editor check -- anyone can view)
- `await interaction.response.defer(ephemeral=True)`
- Get sport from channel, list players: `bot.roster_store.list_players(sport)`
- Sort alphabetically by name: `sorted(players, key=lambda p: p.name.lower())` (per D-13)
- **Empty roster:** Show embed with description "No roster players imported for {sport} yet. An editor can run /roster-import to load the roster."
- **Build embeds (per D-14, D-15):** Split at MAX_FIELDS_PER_EMBED (25). Each player field:

  - If class_year is empty, omit the parenthetical

  - Footer on last embed: `f"Last updated: {now_str}"` with UTC timestamp
  - Color: KU_BLUE (0x0051BA)
- Send: `await interaction.edit_original_response(embeds=embeds[:10])`, then `followup.send` for overflow (same pattern as transfers.py line 218-220)
