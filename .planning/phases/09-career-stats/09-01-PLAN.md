3. Create `src/bot/stats/basketball.py` (per D-14, D-16, INFRA-02):
   ```python
   """CBBD API integration for basketball career stats."""
   import difflib
   import logging
   from datetime import datetime
   import cbbd
   from bot.config import Settings

   logger = logging.getLogger(__name__)

   async def fetch_basketball_stats(settings: Settings, player_name: str, school: str) -> dict | None:
       """Fetch basketball career stats from CBBD API.
       Returns stats dict or None if player not found or API key missing.
       """
   ```
   Implementation details:
   - If `settings.cbbd_api_key` is empty, return None immediately
   - Create `cbbd.Configuration(access_token=settings.cbbd_api_key)`
   - Player ID resolution via roster lookup (per D-16):
     - Get current year roster: `cbbd.TeamsApi(api_client).get_team_roster(season=current_year, team=school)`
     - Try exact match first: `p.name.lower() == player_name.lower()`
     - If no exact match, use `difflib.get_close_matches(player_name, [p.name for p in roster], n=1, cutoff=0.6)`
     - If still no match, try previous year's roster
     - If no match found, return None
   - Query stats: `cbbd.StatsApi(api_client).get_player_season_stats(season=year, team=school)` for last 6 years
   - Filter results to matched player name
   - Build stats dict:
     ```python
     {
         "sport": "basketball",
         "player_id": str(player_match.id) if hasattr(player_match, 'id') else "",
         "player_name": player_match.name,
         "seasons": {
             "2024": {
                 "team": "Kansas",
                 "games": 32,
                 "points": 480,
                 "assists": 128,
                 "rebounds_total": 192,
                 "fg_pct": 0.455,
                 "fg3_pct": 0.372,
             }
         }
     }
     ```
   - Extract from CBBD response objects: `s.games`, `s.points`, `s.assists`, `s.rebounds.total` (or 0 if None), `s.field_goals.pct` (or 0.0 if None), `s.three_point_field_goals.pct` (or 0.0 if None)
   - Wrap entire function body in try/except, log warnings, return None on failure
